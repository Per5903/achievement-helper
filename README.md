# Achievement Helper (Fabric 26.2)

[![Build](https://github.com/Per5903/achievement-helper/actions/workflows/build.yml/badge.svg)](https://github.com/Per5903/achievement-helper/actions/workflows/build.yml)
**Скачать:** [последний релиз](https://github.com/Per5903/achievement-helper/releases/latest)

Клиентский мод: показывает, **что осталось** сделать для ачивки, иконками, а не текстом.
Работает в одиночной игре и на любых серверах (на сервер ставить не нужно).

## Что уже есть (v0.1)
- **HUD (левый верхний угол)**: закреплённые цели и «автопилот» (лучшая следующая цель).
  Иконка, название, `6/40`, полоска прогресса и сетка иконок недостающего: еда, биомы, мобы, варианты кошек и т.д.
- **Тост «+1»** при выполнении пункта ачивки-чеклиста (иконка ачивки, иконка полученного, `7/40`).
- **Чек-лист (J)**: все ачивки цветными клетками.
  Зелёная — готово, жёлтая — начато, серая — доступно, тёмная — закрыто; золотая рамка — закреплено. Клик закрепляет.
  Внизу панель со всем, что осталось, у наведённой ачивки.
- **Цепочки-подсказки для всех 117 ванильных ачивок из одного действия.** Например, `сырое железо + печь → слиток`
  вместо текста. Где без слов не обойтись (рейд, «не кликай по яйцу»), есть одна короткая строка ru/en.
- **Автопилот предлагает сначала лёгкое**: у каждой подсказки есть сложность от 1 (первые минуты) до 5 (эндгейм).
- **Подсказка к предмету**: «★ Нужно для: Сбалансированная диета».
- **Подсветка мобов**: золотой контур на мобах, нужных для целей на HUD (закреплённых и предложенной),
  во всём радиусе прогрузки. Приручённые не подсвечиваются. `highlightOnlyVisible: true` в конфиге оставляет
  подсветку только в прямой видимости (для серверов, где контур сквозь стены запрещён).
- **Напоминание о месте**: при входе в биом из подсказки (например, Луга для «Звуков музыки») появляется золотой тост.
  Новые биомы для «Пора в путь» отмечаются обычным тостом «+1».
- **Фильтры в чек-листе** (кнопки-иконки): все / можно сейчас / начатые / лёгкие / закреплённые / готовые.
- **Подробно об ачивке** (ПКМ по клетке в чек-листе): всё, что осталось, и всё, что готово, крупно и с подписями.
  Например, каких кошек ещё приручить.
- **Модели мобов**: кошки, волки и лягушки показаны нужным окрасом вместо одинаковых яиц призыва.
- **Чем кормить**: у животных в «Двое на двое» в уголке иконки корм для разведения, у кошек и волков то,
  чем приручать (`feeding.json`). Подсказка поясняет особые случаи («мулы: скрести лошадь с ослом»).
  Для животных из других модов корм определяется автоматически.
- **Подсветка нужных предметов**: золотая рамка в сундуках и инвентаре, контур у предметов на земле.
  Содержимое закрытого сундука клиенту неизвестно, поэтому нужные предметы подсвечиваются, когда сундук открыт.
- **Расположение панели**: сторона и верх/низ в настройках, а «Переместить панель мышью…» открывает экран,
  где панель перетаскивается мышью (колесо меняет размер, стрелки двигают на 1 пиксель).
- **Настройки** (компаратор в углу чек-листа или кнопка в Mod Menu): сторона, верх/низ, размер, ширина, сколько целей
  и рядов иконок показывать, названия вкл/выкл (компактный режим), пояснения, модели мобов, тосты, подсветка.
- Иконки находятся автоматически по названиям критериев (реестры предметов, блоков, мобов) и по таблице
  `assets/achievehelper/icons.json` (биомы, варианты мобов).
  В ванили 26.2 **все** критерии получают иконку (это проверяет game-тест).

| Клавиша | Действие |
|---|---|
| J | Чек-лист ачивок |
| H | Показать/скрыть HUD |
| N | Предложить другую цель |
| ЛКМ / ПКМ в чек-листе | Закрепить / подробно |
| M | Закрепить предложенную цель |

Настройки и закрепы: `config/achievehelper.json`.

## Подсказки для своих ачивок (моды, модпаки, ресурс-паки)
Положи `assets/<любой_namespace>/achievehelper_hints/<файл>.json`:
```json
{
  "mymod:tech/first_gear": { "effort": 2, "steps": ["iron_ingot", "+", "mymod:press", ">", "mymod:gear"] },
  "mymod:explore/volcano": ["entity:blaze", "|", "biome:mymod:volcano", "#Y120"]
}
```
Варианты мобов в `assets/achievehelper/icons.json` задаются так:
`{"item": "<запасная иконка>", "mob": "minecraft:cat", "component": "minecraft:cat/variant", "registry": "minecraft:cat_variant"}`,
где название критерия ачивки — это id варианта.

Токены: предмет или блок, `entity:<моб>` (яйцо призыва), `biome:<биом>`, `>` стрелка, `+` плюс, `|` пауза,
`#текст` (короткие числа: `#50m`, `#Y-58`). Необязательная строка-пояснение берётся из ключа перевода
`achievehelper.hint.<namespace>.<путь через точки>`.

## Сборка
```bash
./gradlew build                # jar → build/libs/achievehelper-<версия>.jar
./gradlew test                 # юнит-тесты ядра (без Minecraft)
./gradlew runClient            # запустить игру с модом
./gradlew runClientGameTest    # настоящий клиент: мир, команды, скриншоты → build/run/clientGameTest/screenshots
```
Gradle запускается на Java 21–25. JDK 25 для компиляции он скачает сам (foojay), если его нет.

## Релиз
1. Поднять `version` в `gradle.properties` и дописать раздел в `CHANGELOG.md`.
2. `git tag v<версия> && git push --tags` — GitHub Actions соберёт jar и создаст релиз.
3. Для Modrinth один раз: в настройках репозитория добавить секрет `MODRINTH_TOKEN`
   (Modrinth → Settings → PATs, право *Create versions*) и переменную `MODRINTH_PROJECT_ID` (ID проекта).

## Структура
```
core/      чистая Java без Minecraft: Goal, GoalRanker, ProgressDiff, PinList, CriterionNames, Hint (+ тесты)
client/    слой под конкретную версию MC: трекер, HUD, тост, экран, клавиши, иконки, конфиг
mixin/     ClientAdvancements (инъекция + accessor) и EntityRenderer (контур): всё, что трогает ванильный код
gametest/  клиентский game-тест Fabric
```
Порт на новую версию MC: поднять версии в `gradle.properties`, починить `client/` и `mixin/`.
`core/` и его тесты не меняются.
